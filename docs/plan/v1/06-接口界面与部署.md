## 阶段目标

把经过评测的 RAG 链路封装为 API 和可演示界面，并补齐基本运行、日志和隐私保护能力。

## 实施任务

- [ ] 实现 `/v1/query`、`/v1/retrieve`、`/v1/laws` 和 `/v1/health`。
- [ ] 实现指定法律增量重建索引接口或管理命令。
- [x] 使用 Streamlit 建立演示界面。
- [x] 展示结论、限制、法条原文及原始文件位置。
- [ ] 增加超时、限流、错误处理和健康检查。
- [ ] 对日志中的身份证号、手机号等敏感信息脱敏。
- [ ] 编写本地运行、配置、重建索引和故障排查说明。

## 验收标准

- [ ] API schema 稳定并有自动化测试。
- [ ] 用户可从界面完成提问并查看法条依据。
- [ ] Chroma 和 BM25 数据重启后仍可使用。
- [ ] 缺少模型密钥或索引时能返回明确错误。
- [ ] 日志不记录用户敏感信息原文。
