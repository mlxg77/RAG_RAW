# 阶段 1：文档解析与法条切分

> 版本：V1  
> 状态：done

## 阶段目标

把 PDF、DOCX 和 Markdown 法律文件转换成结构统一、可追溯的法条 JSONL。

## 实施任务

- [x] 分别实现 PDF、DOCX、Markdown loader。
- [x] 清理页眉页脚、异常换行、全角空格和不可见字符。
- [x] 识别编、章、节、条，并正确继承层级信息。
- [x] 默认按条切分，超长条文再按自然段拆分。
- [x] 生成稳定的 `chunk_id` 和正文哈希。
- [x] 输出 `data/processed/articles.jsonl`。
- [x] 生成每部法律的条数、空条、重复条和解析异常报告。

## 验收标准

- [x] 三种格式均有自动化解析测试。
- [x] 每部法律随机抽查 10 条，条号、正文、章节和页码正确率达到 99%。
- [x] 不把目录中的条号误识别为正文。
- [x] 跨页法条没有被错误拆断。
- [x] 同一批输入重复运行，`chunk_id` 保持一致。
