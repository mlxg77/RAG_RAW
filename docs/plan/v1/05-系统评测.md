# 阶段 5：系统评测

> 版本：V1  
> 状态：draft

## 阶段目标

建立可重复运行的检索和生成评测，确保修改组件或参数后能够量化判断效果变化。

## 实施任务

- [ ] 将评测集扩充到至少 100 题。
- [ ] 覆盖直接查询、口语场景、跨条文、多法律、歧义和范围外问题。
- [ ] 自动计算 Recall@K、MRR、nDCG 和检索延迟。
- [ ] 评估引用正确率、证据忠实度、完整性和拒答准确率。
- [ ] 保存数据版本、模型、参数和提示词版本。
- [ ] 输出机器可读结果和 Markdown 评测报告。

## 质量门槛

- [ ] Recall@10 不低于 90%。
- [ ] 引用精确匹配率为 100%。
- [ ] 伪造引用率为 0%。
- [ ] 范围外问题拒答准确率不低于 90%。
- [ ] 所有指标均可以通过一条命令复现。
