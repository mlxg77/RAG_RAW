# 阶段 2：检索基线

> 版本：V1  
> 状态：draft

## 阶段目标

建立 BM25、Chroma 向量检索和 RRF 混合检索，并用固定评测集得到第一份量化基线。

## 技术约定

- Chroma 通过 `langchain-chroma` 接入，持久化目录为 `indexes/chroma/`。
- Collection 名称为 `law_articles`。
- Chroma 文档 ID 使用 `chunk_id`。
- BM25 索引保存在 `indexes/bm25/`。
- 两路结果通过 `chunk_id` 合并。
- 解析后的法条转换为 LangChain `Document`，正文放入 `page_content`，结构信息放入 `metadata`。

## 实施任务

- [ ] 完成中文分词和 BM25 检索。
- [ ] 通过 LangChain provider 选定 embedding 模型并记录模型名称及版本。
- [ ] 使用 `langchain_chroma.Chroma` 写入文档、向量和 metadata。
- [ ] 实现向量相似度检索。
- [ ] 实现 RRF 结果融合。
- [ ] 支持按法律名称过滤。
- [ ] 提供输入问题并输出前 10 条结果的 CLI。
- [ ] 计算 Recall@1/3/5/10、MRR 和 P95 延迟。

## 验收标准

- [ ] 混合检索 Recall@10 不低于 90%。
- [ ] 混合检索整体效果优于单独使用 BM25 或向量检索。
- [ ] 重建索引后，相同查询的结果可重复。
- [ ] 每个结果包含法律名、条号、正文、分数和 `chunk_id`。
