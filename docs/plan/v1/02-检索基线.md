# 阶段 2：检索基线

> 版本：V1  
> 状态：done（存在已记录限制）

## 阶段目标

建立 BM25、Chroma 向量检索和 RRF 混合检索，并用固定评测集得到第一份量化基线。

## 技术约定

- Chroma 通过 `langchain-chroma` 接入，持久化目录为 `indexes/chroma/`。
- Collection 名称为 `law_articles`。
- Chroma 文档 ID 使用 `chunk_id`。
- BM25 索引保存在 `indexes/bm25/`。
- 两路结果通过 `chunk_id` 合并。
- 解析后的法条转换为 LangChain `Document`，法律名、层级、条号和正文组成的增强检索文本放入 `page_content`，稳定结构信息放入 `metadata`；检索命中后通过 `chunk_id` 回映原始正文。

## 验收标准

- [x] 混合检索 Recall@10 不低于 90%。
- [x] 混合检索整体效果优于单独使用 BM25 或向量检索。
- [ ] 重建索引后，相同查询的结果可重复。
  - 当前达到质量指标可重复；使用远程 embedding 重新计算文档向量后，近分、非关键候选的精确顺序存在漂移。同一索引上的重复查询稳定。
- [x] 每个结果包含法律名、条号、正文、分数和 `chunk_id`。
