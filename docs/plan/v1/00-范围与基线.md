# 阶段 0：范围与基线

> 版本：V1  
> 状态：ready

## 阶段目标

明确 V1 只处理当前 `data/` 中的 15 部法律，建立项目骨架、基础法律清单和第一批检索评测问题。

## 实施任务

- [ ] 初始化 Python 项目、依赖和环境变量示例。
- [ ] 安装 `langchain-core`、`langchain-chroma` 及实际模型供应商对应的 LangChain 集成包。
- [ ] 用最小示例验证 LangChain 可以调用 embedding、写入 Chroma 并调用大模型。
- [ ] 建立 `data/raw`、`data/processed`、`data/eval` 和 `indexes` 目录。
- [ ] 将现有法律文件整理到 `data/raw`。
- [ ] 创建只包含 `law_id`、法律名称和文件路径的 `data/manifest.yaml`。
- [ ] 设计 30 个问题，其中至少 5 个属于知识库范围外或应当拒答的问题。
- [ ] 为可回答问题标注预期法律名称和条号。

## 验收标准

- [ ] manifest 覆盖全部 15 个文件，且路径有效。
- [ ] 30 个问题均有唯一 ID 和问题类型。
- [ ] 每个可回答问题均有人工标注的目标法条。
- [ ] 项目依赖可以在全新环境中安装。
- [ ] LangChain 最小示例可以在项目环境中成功运行。
