# 阶段 4：答案生成与引用校验

> 版本：V1  
> 状态：done（存在已记录限制）

## 阶段目标

使用 LangChain 让模型只依据检索证据生成结构化回答，并通过程序校验法律名称、条号和引文。

## 实施任务

- [x] 通过 LangChain provider 集成建立 LLM 调用接口。
- [x] 使用 PromptTemplate 编写系统提示词。
- [x] 使用 Pydantic 和 `with_structured_output` 定义回答 Schema。
- [x] 使用 LCEL 串联上下文、Prompt、LLM 和输出解析。
- [x] 输出结论、分析、适用条件、引用、限制和追问。
- [x] 校验引用的 `chunk_id` 是否来自本次上下文。
- [x] 校验法律名、条号与 chunk metadata 是否一致。
- [x] 校验引文是否为法条原文的连续子串。
- [x] 实现低相关度拒答和关键事实追问。
- [x] 引用校验失败时重新生成一次，再失败则安全降级。

## 验收标准

- [x] 所有展示引用都能映射到检索证据。
- [x] 不存在的法律或条号不会被当作真实依据展示。
- [ ] 知识库范围外问题能够明确拒答（q030 当前表现为安全降级，已转阶段 5 代办）。
- [x] 结构化输出解析失败时有可用的降级响应。
