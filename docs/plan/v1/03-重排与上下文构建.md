# 阶段 3：重排与上下文构建

> 版本：V1  
> 状态：done

## 阶段目标

对混合检索候选结果进行精排，构建无重复、证据标识清楚且长度受控的模型上下文。

## 实施任务

- [x] 选定中文或多语言 reranker。
- [x] 对融合后的前 10 条候选法条重排。
- [x] 相同法条和相同正文去重。
- [x] 对超长法条选取相关段落，同时保留完整条号。
- [x] 必要时补充相邻法条。
- [x] 为每段上下文分配不可混淆的证据 ID。
- [x] 设置上下文 token 上限和截断策略。

## 验收标准

- [x] Recall@5 和前三条平均相关性优于阶段 2 基线。
- [x] 上下文中不存在重复法条。
- [x] 每个上下文片段均可映射回原始 chunk。
- [x] 上下文超出长度限制时不会从句子中间粗暴截断。
