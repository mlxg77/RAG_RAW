# 项目文档中心

本目录用于保存项目各阶段的实施规划，以及实施完成后沉淀的知识。

## 目录结构

```text
docs/
├─ plan/
│  ├─ v1/        # 第一版的阶段实施规划
│  └─ v2/        # 第二版的阶段实施规划
└─ note/
   ├─ v1/        # 第一版实施后的知识沉淀
   └─ v2/        # 第二版实施后的知识沉淀
```

## 使用约定

- `plan` 在开始开发前编写，描述目标、范围、任务、产物和验收标准。
- `note` 在完成阶段后编写，只记录实际结果，不把未经验证的设想当成结论。
- 同一阶段的 plan 和 note 使用相同文件名，方便互相对照。
- V1 以完成可运行的法律 RAG MVP 为目标。
- V2 用于记录经过 V1 评测后确定的优化工作，暂不提前设计具体内容。
- `docs/plan/v1/V1整体规划.md` 是 V1 全局路线图；同目录下保存各阶段的详细规划。

## 阶段文件命名

```text
V1整体规划.md
00-范围与基线.md
01-文档解析与法条切分.md
02-检索基线.md
03-重排与上下文构建.md
04-答案生成与引用校验.md
05-系统评测.md
06-接口界面与部署.md
```

## 文档状态

每份规划在标题下标记以下状态之一：

- `draft`：尚未确认；
- `ready`：可以开始实施；
- `in-progress`：正在实施；
- `done`：已完成并通过验收；
- `blocked`：存在阻塞项。
